## Gorev
Kare şeklindeki büyük deponun kenarlarından dolanarak mola odasına ulaş. İç içe döngüler kullanmanın tam zamanı.

## Ipucu1
Önce düz bir çizgiyi geçmek için bir `for` döngüsü yaz. Sonra bu döngüyü ve `sagaDon();` komutunu başka bir dış `for` döngüsünün içine al.

## Ipucu2
Dıştaki döngü 3 kez (3 kenar için), içteki döngü ise 4 kez (her kenardaki adımlar için) çalışmalı.

## Cozum
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        ilerle();
    }
    sagaDon();
}

## VardiyaNotu
Büyük deponun çevresi kısacık bir kodla dönüldü. Amiri bile ağlatacak bir mühendislik harikası.
