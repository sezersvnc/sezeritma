## Gorev
Yerde bir sürü çikolata var ama amir sadece 5 tanesine izin veriyor. Sayacın 5 olmadan ve mola odasına varmadan ilerlemeye devam et, sayac 5 olunca sadece ilerle.

## Ipucu1
`while` döngünün içine iki şartı `&&` (ve) ile bağlayabilirsin: `(sayac < 5 && !molaOdasindaMiyim())`

## Ipucu2
İlk `while` ile sadece 5 çikolata topla. Döngü bittiğinde hâlâ mola odasında değilsen, kalan yolu ikinci bir `while` ile yürü.

## Cozum
int sayac = 0;
while (sayac < 5 && !molaOdasindaMiyim()) {
    if (ustumdeCikolataVar()) {
        kap();
        sayac++;
    } else {
        ilerle();
    }
}
while (!molaOdasindaMiyim()) {
    ilerle();
}

## VardiyaNotu
Nefsine hakim oldun ve 5'te durdun. Ayın elemanı olmaya çok yakınsın.
