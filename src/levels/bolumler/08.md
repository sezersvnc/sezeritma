## Gorev
Depo bloğunun dört bir yanı çikolata dolu. Bloğun etrafını dolaş, on iki çikolatanın hepsini topla ve mola odasına gel.

## Ipucu1
Her kenar aynı: dört kere ilerle-kap, sonra köşeyi dön. Aynı şeyi üç kenarda tekrarlıyorsun.

## Ipucu2
Dış döngü kenarları saysın, iç döngü o kenardaki dört kareyi yürüsün. Dış döngünün sonunda `sagaDon();` var. Üç kenar bittikten sonra üç kare daha ilerle.

## Cozum
for (int i = 0; i < 3; i++) {
  for (int j = 0; j < 4; j++) {
    ilerle();
    kap();
  }
  sagaDon();
}
ilerle();
ilerle();
ilerle();
