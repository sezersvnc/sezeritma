## Yon

## Gorev
Koridorun sonunda palet var. Sezer çarpmadan dönmeli.

## Ipucu1
Körlemesine ilerlersen palete çarparsın. Önce bakman gerekiyor.

## Ipucu2
Döngünün içinde `if (onumdePaletVar()) { sagaDon(); }` yaz, ondan sonra ilerle.

## Cozum
while (!molaOdasindaMiyim()) {
  if (onumdePaletVar()) {
    sagaDon();
  }
  ilerle();
}

## VardiyaNotu
Palete çarpmadı. Amirin bundan haberi yok ama olsaydı gurur duyardı.
