# 11 — Rafta Ne Var?

vardiya: 3
kavram: if / else
izinliKomutlar: ilerle, sagaDon, solaDon, kap, molaOdasindaMiyim, onumdePaletVar, ustumdeCikolataVar
izinliYapilar: for, while, if, else, degisken
hedefSatir: 5

## Harita
###########
#S.C.CC..M#
###########

## Yon
dogu

## Gorev
Çikolatalar düzensiz dizilmiş, hangi karede olduklarını önceden bilmiyorsun. Hepsini topla ve mola odasına git.

## Ipucu1
Her karede iki ihtimal var: ya çikolata vardır ya yoktur. İkisinde de yapılacak şey farklı.

## Ipucu2
`if (ustumdeCikolataVar()) { kap(); } else { ilerle(); }` — çikolata varsa kap, yoksa ilerle.

## Cozum
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
  } else {
    ilerle();
  }
}

## VardiyaNotu
Üç çikolata daha. Sezer artık nereye bakacağını biliyor.
