## Gorev
Yerde rastgele dağılmış çikolatalar var. Bastığın karede çikolata varsa kap, yoksa yoluna devam et.

## Ipucu1
Bu kez iki farklı durum var: çikolata varsa kapılacak, yoksa ilerlenecek. `else` tam da bunun için var.

## Ipucu2
`if (ustumdeCikolataVar())` içine `kap();` yaz, hemen altına `else { ilerle(); }` ekle. Hepsini bir `while` döngüsüne sar.

## Cozum
while (!molaOdasindaMiyim()) {
    if (ustumdeCikolataVar()) {
        kap();
    } else {
        ilerle();
    }
}
