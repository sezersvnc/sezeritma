## Gorev
Bu koridordaki çikolataları topla ve kaç tane kaptığını say. Sayacı yandaki panelden canlı izleyebilirsin.

## Ipucu1
Bir sayıyı hatırlamak için değişken kullanılır: `int sayac = 0;` diye başlar.

## Ipucu2
Döngüden önce `int sayac = 0;` yaz. Her `kap();` satırının hemen altına `sayac++;` ekle — sağdaki panelde sayacın arttığını göreceksin.

## Cozum
int sayac = 0;
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
    sayac++;
  } else {
    ilerle();
  }
}
