## Gorev
Çikolataları toplarken sayısını aklında tutman gerek. Bir `sayac` değişkeni oluştur ve her çikolata kaptığında onu artır.

## Ipucu1
Döngüden önce `int sayac = 0;` diyerek başla. Çikolatayı kaptığın `if` bloğunun içinde sayacı artır.

## Ipucu2
Sayacı artırmak için `sayac++;` ya da `sayac = sayac + 1;` yazabilirsin. Yan panelde sayacın değişimini izle.

## Cozum
int sayac = 0;
while (!molaOdasindaMiyim()) {
    if (ustumdeCikolataVar()) {
        kap();
        sayac++;
    } else {
        ilerle();
    }
}
