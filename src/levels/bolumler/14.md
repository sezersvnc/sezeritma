## Gorev
Koridorun sonuna kadar yürü, orada aşağı dön ve mola odasına in. Nerede duracağını iki şey birden belirliyor.

## Ipucu1
İlk döngü mola odasına varınca değil, palete rastlayınca durmalı. Ama ikisine de hazır olmalısın.

## Ipucu2
`while (!molaOdasindaMiyim() && !onumdePaletVar())` — iki koşul da doğru olduğu sürece devam eder. `&&` "ve" demek.

## Cozum
while (!molaOdasindaMiyim() && !onumdePaletVar()) {
  ilerle();
}
sagaDon();
while (!molaOdasindaMiyim()) {
  ilerle();
}
