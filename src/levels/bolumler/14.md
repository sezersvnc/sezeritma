## Gorev
Rafta tam beş çikolata var ve amir daha fazlasına göz yummaz. Beşini topla, sonra mola odasına geç.

## Ipucu1
`while` döngünün içine iki şartı `&&` (ve) ile bağlayabilirsin: `(sayac < 5 && !molaOdasindaMiyim())`

## Ipucu2
İlk `while` ile beş çikolatayı topla. Döngü bittiğinde hâlâ mola odasında değilsen, kalan yolu ikinci bir `while` ile yürü.

## Cozum
int sayac = 0;
while (sayac < 5 && !molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
    sayac++;
  } else {
    ilerle();
  }
}
while (!molaOdasindaMiyim()) {
  ilerle();
}
