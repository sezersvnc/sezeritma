## Gorev
Bu koridorda üç ayrı durum var: çikolata, palet ya da açık yol. Üçü için de ne yapacağını söylemen gerekiyor.

## Ipucu1
`if` ve `else` iki yol açıyor. Üçüncü bir durum varsa araya bir tane daha koyman gerek.

## Ipucu2
`if (...) { } else if (...) { } else { }` sırasıyla çikolatayı kap, palete rastlayınca dön, kalan durumda ilerle.

## Cozum
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
  } else if (onumdePaletVar()) {
    sagaDon();
  } else {
    ilerle();
  }
}

Üç ihtimal, üç dal, tek döngü. Sezer artık her duruma hazır.
