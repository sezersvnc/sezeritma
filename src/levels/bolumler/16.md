## Gorev
Son vardiya, son görev. Labirentin her yerinde çikolata var. Öğrendiğin her şeyi birleştir, hepsini topla ve mola odasına zaferle gir.

## Ipucu1
Her karede üç ihtimal var: çikolata, palet, ya da açık yol. Üçü için üç ayrı davranış gerekiyor.

## Ipucu2
`if` ile çikolatayı kap, `else if` ile palete rastlayınca dön, `else` ile ilerle. Tek döngü hepsini halleder.

## Cozum
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
  } else if (onumdePaletVar()) {
    sagaDon();
  } else {
    ilerle();
  }
}
