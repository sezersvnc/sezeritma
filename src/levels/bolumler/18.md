## Gorev
Depo bomboş, hiçbir duvar sana nerede döneceğini söylemiyor. Adımlarını sayman ve doğru anda dönmen gerekiyor.

## Ipucu1
`onumdePaletVar()` burada işe yaramaz, çünkü ortalık açık. Kaç adım attığını yalnızca sen bilebilirsin.

## Ipucu2
Bir `int adim = 0;` sayacı tut, her ilerlemede artır, `if (adim == 3)` olduğunda sağa dön.

## Cozum
int adim = 0;
while (!molaOdasindaMiyim()) {
  if (adim == 3) {
    sagaDon();
  }
  ilerle();
  adim++;
}
