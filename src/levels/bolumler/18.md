## Gorev
Bu kod sonsuz döngüye giriyor. Çalıştır, oyunun sana ne söylediğini oku, sonra döngünün neden bitmediğini bul.

## BaslangicKodu
while (!molaOdasindaMiyim()) {
  if (onumdePaletVar()) {
    sagaDon();
  }
}

## Ipucu1
Döngünün içinde Sezer'in konumunu değiştiren bir şey var mı? Dönmek konum değiştirmez.

## Ipucu2
Koşul "mola odasında değilken" diyor. Ama döngü içinde hiç ilerlenmiyorsa Sezer oraya nasıl varacak? Bir `ilerle();` eksik.

## Cozum
while (!molaOdasindaMiyim()) {
  if (onumdePaletVar()) {
    sagaDon();
  }
  ilerle();
}

## VardiyaNotu
Sonsuz döngü bir hata değil, bir unutkanlıktır: koşulu yanlış yapacak şeyi yazmayı unutursun.
