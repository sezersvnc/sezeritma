## Gorev
Bu kod çalışıyor ama sayaç yanlış sayıyor. Çikolataları topluyor, sayaç ise hep bir adım geride. Satırlardan biri yanlış yerde.

## BaslangicKodu
int sayac = 0;
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
    kap();
  } else {
    ilerle();
    sayac++;
  }
}

## Ipucu1
Sayacı artıran satır hangi dalın içinde? Çikolata kapıldığında mı artıyor, ilerlendiğinde mi?

## Ipucu2
`sayac++;` satırını `else` dalından alıp `kap();` satırının hemen altına taşı. Sayaç kapılanı saymalı, adımı değil.

## Cozum
int sayac = 0;
while (!molaOdasindaMiyim()) {
  if (ustumdeCikolataVar()) {
