## Gorev
Depo bomboş, hiçbir duvar sana yol göstermiyor. Üç adımda bir dönerek kareyi tamamla ve mola odasına in.

## Ipucu1
Sayaç üçe geldiğinde dönmek yetmez; altıda, dokuzda da dönmen gerekiyor. Tek tek yazmak yerine bir kalıp lazım.

## Ipucu2
`%` işleci bölmeden kalanı verir. `adim % 3 == 0` ifadesi üçün katlarında doğru olur; başlangıçtaki sıfırı dışarıda tutmak için `adim > 0` şartını da ekle.

## Cozum
int adim = 0;
while (!molaOdasindaMiyim()) {
  if (adim > 0 && adim % 3 == 0) {
    sagaDon();
  }
  ilerle();
  adim++;
}

## VardiyaNotu
Üç, altı, dokuz. Tek satırda sonsuz bir ritim kurdun.
